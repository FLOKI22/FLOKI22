### 👋 About

- Building products for the Saudi market — Arabic-first, RTL, local payments.
- I own the whole stack: database design, backend, frontend, servers, and security hardening.
- I care about boring, reliable engineering: server-side validation, prepared statements, strict access control, least privilege.


### 🚀 What I'm building

| Project | What it is | Stack |
|---|---|---|
| **[Bahw · بهو](https://bahw.sa)** | Saudi marketplace where creatives (photo, design, dev, video, writing) list services and prices and deal with clients directly. Public beta. | Next.js · TypeScript |
| **[X-Store](https://xstore-dev.cc)** | Storefront for licensed FiveM scripts, built on top of my own licensing system (X-License): Discord OAuth login, card payments with server-side payment verification, automatic license + Discord role delivery, signed short-lived download links, self-service IP binding, coupons, bilingual AR/EN with full RTL. Live. | Next.js · TypeScript · SQLite (WAL) · Discord API · EdfaPay · nginx |
